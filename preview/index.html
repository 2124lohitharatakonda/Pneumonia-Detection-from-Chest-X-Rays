Powered By Deep Learning

Two industry-proven architectures for accurate classification

ResNet50

A 50-layer deep residual network with skip connections that solve the vanishing gradient problem. Pre-trained on ImageNet with 1M+ images, fine-tuned for pneumonia classification.

  • Depth: 50 layers
  • Input: 224×224 RGB
  • Transfer learning from ImageNet
MobileNetV2

A lightweight, efficient CNN designed for mobile and embedded applications. Uses depth-wise separable convolutions to minimize computation while maintaining high accuracy.

  • Efficient depthwise convolutions
  • Low memory footprint
  • Fast inference speed
