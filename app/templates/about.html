About This Project

Automated Chest X-Ray Classification using Deep Learning

Project Overview

This system implements an automated chest X-ray image classification pipeline using state-of-the-art deep learning architectures — MobileNetV2 and ResNet50 — to detect and classify pneumonia from 2D grayscale or colour chest radiographs.

The project was developed as part of the 20CS811 — Project Phase II coursework at R.M.K. Engineering College (Autonomous), R.S.M. Nagar, Kavaraipettai — 601206, March 2024.

Objectives

  • Train and fine-tune MobileNetV2 and ResNet50 on a curated chest X-ray dataset.
  • Achieve high classification accuracy (>98%) for NORMAL vs PNEUMONIA classes.
  • Integrate Manta Ray Optimization (MRO) to improve model convergence.
  • Deliver a user-friendly web interface for real-time predictions.
  • Provide clinical guidance based on the predicted outcome.
